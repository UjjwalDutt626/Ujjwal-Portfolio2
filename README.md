# Ujjwal Dutt Portfolio

Responsive portfolio starter based on the supplied Frame 1 design.

## Folder structure

- `index.html` — page structure/content
- `styles.css` — responsive styling + animations
- `script.js` — mobile menu, scroll reveals, cursor glow and contact form
- `assets/` — add your real portrait, about image and Digitech logo here

## Add your images

Put these files inside `assets/`:

- `profile.png` — transparent hero portrait
- `about-profile.png` — about section portrait
- `digitech-logo.png` — company logo

## Contact form

Open `script.js` and replace:

`const EMAIL = "your-email@example.com";`

with your real email.

The form currently opens the visitor's email app using `mailto:`. For a form that sends without opening an email app, connect Formspree, Web3Forms, or another form backend later.

## Free deployment on Vercel

1. Create a GitHub account.
2. Create a new repository, e.g. `ujjwal-portfolio`.
3. Upload all files from this folder.
4. Go to Vercel and sign in with GitHub.
5. Import the repository.
6. Framework preset: `Other`.
7. Deploy.

Vercel will provide a free `*.vercel.app` URL.
